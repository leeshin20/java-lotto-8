# java-lotto-precourse

## 기능 목록

# 입력
- 로또를 구입 금액을 입력 받는다.
  - [ERROR] 1000원으로 나누어 떨어지지 않으면 예외처리
  - [ERROR] 정수가 아닐 경우 예외처리
- 당첨 번호를 쉼표로 구분하여 입력 받는다.
  - [ERROR] 6개 보다 적거나 많은 정수가 입력되면 예외처리
  - [ERROR] 중복된 당첨 번호가 입력 되면 예외처리
  - [ERROR] 정수, 쉼표 이외의 입력 값이 들어오면 예외처리
- 보너스 번호를 입력 받는다.
  - [ERROR] 당첨 번호와 중복된 보너스 번호인 경우 예외처리
  - [ERROR] 정수가 아닌 경우 예외처리
 
# 출력
- 당첨 통계를 출력한다.

# 로또
- 금액 만큼 로또를 구매한다.
- 구매한 로또 만큼 로또를 발행한다
- 1~45 범위의 수를 랜덤으로 생선한다
  - 하나의 로또에서 중복된 수가 나올 경우 다시 생성한다
- 당첨 번호와 비교하여 각 로또의 당첨 여부를 확인한다
- 모든 당첨 금액을 합산한다
  - 수익률을 산출하고 소수점 둘째 자리에서 반올림한다
